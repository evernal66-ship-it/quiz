# 期末冲刺 · 习概刷题

装到 iPhone 主屏幕的刷题应用。纯前端、离线可用、不联网也能刷。

**已经部署好了，直接用这个网址：** <https://evernal66-ship-it.github.io/quiz/>

---

## 一、装到 iPhone 上（三步，5 分钟）

iOS 不允许随便装 app（除非买 99 美元/年的开发者账号），所以走 **PWA**：网页 + 添加到主屏幕。效果和原生 app 基本一样——全屏、有图标、离线可用、没有地址栏。

### 第 1 步

用 iPhone 的 **Safari** 打开 <https://evernal66-ship-it.github.io/quiz/>

> 必须 Safari。微信内置浏览器、Chrome for iOS 都不支持「添加到主屏幕」。

### 第 2 步

点底部 **分享** 按钮（方框带向上箭头）→ 往下滑 → **添加到主屏幕**

### 第 3 步

名字默认「期末冲刺」，点 **添加**。回桌面就能看到图标，点开是全屏的。

第一次打开请等两三秒（在缓存离线数据），之后就断网也能用。

## 二、题库

| 模块 | 内容 | 数量 |
| :--- | :--- | ---: |
| 刷题 | 选择题，每题带出处解析 | **272** |
| 简答 | 必背知识点（按教材页码） | **36** |
| 论述 | 论述题要点 | **18** |

来源三份材料：

1. 老师发的《26年下学期选择题汇总（可发给学生）.docx》—— 252 题
2. 《期末复习资料-精简版-B5.pdf》—— 272 题完整题库（含答案）
3. 《习近平新时代中国特色社会主义思想概论》教材（367 页）—— 解析里的原文引用

> 老师发的文档是复习资料 272 题的**精简版**，少 20 道（第八章缺 5 道、第九章缺 15 道），其余 16 章一道不差。本应用按 **272 道**收录，被删掉的 20 道标「精简版未收录」黄标，可在「我的 → 精简版未收录」里单独刷。

**272 道选择题都有一条手写解析**：考点是什么 → 教材原文怎么说的（标页码）→ 为什么选它 → 其他选项错在哪。不是机器生成的套话。

简答和论述按需求只给答案、不写解析（老师划的重点原文）。

## 三、功能

| 功能 | 怎么用 |
| :--- | :--- |
| 刷题 | 单选/多选都是先选项、再点「提交答案」才判分 |
| 乱序 | 默认就打乱；点右上角 🔀 重新打乱一次 |
| 模拟测试 | 右上角 ⏱ → 从 18 章**平均抽** 25 单选 + 10 多选，计时 35 题，交卷出成绩单（总分、用时、各章正确率、逐题回顾） |
| 刷错题 | 我的 → 刷错题。每进一次换一次随机顺序，**答对自动移出错题本** |
| 收藏 | 题目左下角 ☆，之后在「我的 → 我的收藏」里集中看 |
| 简答/论述 | 也在刷题流程里（筛选「题型」可只看它们）；点「显示答案」→ 自评「记住了 / 再背一遍」 |
| 统计 | 我的 → 累计作答 / 总正确率 / 待复习、各题型正确率、各章正确率 |
| 筛选 | 右上角 ☰ → 按章节（19 个）、按题型（选择/简答/论述）、按状态（未做过/错题/收藏/精简版未收录） |
| 滑动 | 左右滑切上一题/下一题 |

做题记录存在浏览器本地（localStorage），关掉再打开还在。换手机或清 Safari 缓存会丢——这是 PWA 的固有限制。

## 四、如果 GitHub 打不开

国内访问 GitHub Pages 有时慢。备选：

- **Cloudflare Pages**：<https://pages.cloudflare.com> → Connect to Git → 选同一个仓库 → 自动部署，国内一般能开
- 学校/公司有静态服务器，把 `app/` 里的文件原样传上去也一样

> 判断标准：iPhone Safari 能打开那个网址，就能添加到主屏幕。PWA 不挑托管商。

## 五、目录结构

`app/` 是全部成品（上传时全部拍平放在仓库根目录）：

```
app/
├── index.html          页面骨架
├── style.css           样式（跟随系统深/浅色）
├── app.js              全部逻辑：出题、判分、乱序、模考、筛选、存储
├── manifest.json       PWA 配置（图标、全屏、主题色）
├── sw.js               Service Worker，离线缓存
├── bank.js             题库（272 选择 + 36 简答 + 18 论述，281 KB）
├── icon-180.png        iPhone 主屏幕图标
├── icon-192.png
└── icon-512.png
```

> 仓库里是拍平版本（`bank.js`、`icon-*.png` 直接放根目录），因为 GitHub 网页上传不支持目录。本地 `app/` 目录结构相同。

`_extract/` 是解析与构建脚本（不用管）：docx/pdf 解析、272 题抓取、逐题解析生成、题库打包、图标绘制、CDP 自动化测试。

## 六、改题 / 加题

题库在 `app/bank.js`（线上）或 `app/data/bank.js`（本地），结构：

```js
window.BANK = {
  meta:      { title, generated, counts },
  chapters:  [{ name, id }],
  choice:    [{ id, ch, t:'single'|'multi', s, o:{A,B,C,D}, a:'AB', at, src, an, dm }],
  short:     [{ id, page, title, body }],
  essay:     [{ id, group, q, points:[] }]
};
```

- `a` 是答案字母，多选按字母顺序拼（如 `"ABD"`）
- `src` 是出处（「教材 P186 · 坚持法律面前人人平等」），`an` 是解析正文
- `dm: true` 表示这道题老师发的精简版里没有
- 改完刷新页面即可，不用构建

**改了内容记得改 `sw.js` 里的版本号**（`const V = 'szk-v7'` → `v8`），否则浏览器会一直用旧缓存。
